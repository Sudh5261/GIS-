# 🌍 Campus Eco GIS Platform

## Overview
The **Campus Eco GIS Platform** is a front-end web interface designed to visualize and report campus waste, access eco-guides, and provide feedback. It simulates a GIS-based dashboard for environmental awareness and sustainability.

## Features
- **Navbar**: Logo, search bar, language selector, report waste button, and account icon.
- **Sidebar Navigation**:
  - Dashboard
  - Waste Map
  - Eco Guide
  - Feedback
  - Contact Us
- **Main Content**:
  - Waste Map Overview
  - Locations Captured
  - Eco-Tips Section
- **Footer**:
  - Resources
  - Community & Support
  - About Us

## Tech Stack
- **HTML5** for structure
- **CSS3** for styling
- **Font Awesome** for icons
- External links to **AppSheet** for GIS data visualization
